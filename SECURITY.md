# Security policy

## Supported versions

Security fixes are provided for the latest release on `main`.

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues. Use GitHub's private
vulnerability-reporting feature for this repository. If it is not enabled,
contact a repository maintainer privately through GitHub before publishing any
details.

Reports should include impact, reproduction steps, affected versions, and any
suggested mitigation. We will acknowledge a report and coordinate disclosure
before publishing a fix.
